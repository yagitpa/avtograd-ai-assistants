# Демонстрация на десять минут

> Учебный проект «АвтоГрад». Дилер, модели, цены, имена и телефоны вымышлены.

Сценарий для живого показа и для записи прохода. Порядок выбран не по разделам
проекта, а по одному сюжету: **ассистент полезен, пока ему можно верить, и весь
проект — про то, как это обеспечено.**

Поэтому демонстрация начинается не с удачного ответа, а заканчивается им.

## Перед началом

```bash
python tools/demo_check.py
```

Пока в выводе есть строки с `!`, начинать нельзя: каждая означает, что один из
пунктов ниже не сработает. Предупреждения с `~` допустимы, их видно заранее.

Три окна на экране: Telegram с клиентским ботом, Telegram с консолью эскалаций,
терминал. Браузер с n8n — четвёртым, понадобится на минуте семь.

Ядро и боты должны быть подняты:

```bash
python tools/api.py
```

```bash
python tools/telegram_bots.py
```

---

## 0:00 — 1:00 · Обычный день

**Показать:** в клиентском боте спросить *«Подбираю кроссовер до трёх миллионов,
что есть?»*

Ассистент отвечает позициями из стока с ценами и статусами.

**Сказать:** это то, ради чего проект затевался, и это самая простая его часть.
Дальше — про девять случаев из десяти, когда всё идёт не так.

---

## 1:00 — 2:30 · Красная линия

**Показать:** написать *«Готов купить сегодня, если дадите скидку 500 000»*.

Ассистент называет действующие акции и не обещает скидку.

Затем: *«Двигатель застучал через месяц после покупки. Это же гарантийный
случай?»* — ассистент описывает порядок обращения и **не выносит решения по
гарантии**.

**Сказать:** дело не в том, что модель вежливая. Ответ проходит детерминированный
валидатор перед отправкой. Показать в терминале:

```bash
python tests/test_core.py
```

Пятьдесят девять проверок — каждая заперла дефект, который однажды уже прошёл к
клиенту. Формулировка «признать случай гарантийным», «процент» вместо «оцен»,
число с пробелом между разрядами: валидатор ловит смысл, а не слова.

**Главное:** решение о гарантии и о скидке стоит денег. Ассистент их не
принимает — не потому, что ему запрещено промптом, а потому что текст с таким
решением физически не уйдёт клиенту.

---

## 2:30 — 4:30 · Передача человеку

**Показать:** написать *«Третий раз сдаю машину с одним и тем же стуком. Дайте
живого менеджера»*.

1. Клиент получает ответ, что обращение передано.
2. **В консоли эскалаций появляется карточка** с последними репликами и кнопками.
3. Нажать «Взять диалог» — клиенту уходит строка о подключении сотрудника.
4. Написать в консоли что-нибудь от лица менеджера — **приходит в чат клиента**.
5. Ответить из чата клиента — **приходит в консоль**.
6. `/done` — клиенту уходит строка о возврате, ассистент снова отвечает.

**Сказать:** консоль — отдельный, третий бот. Не режим внутри кадрового, потому
что в карточке видны имя, телефон и VIN клиента, а кадровый канал таких данных
носить не должен.

**Сказать честно:** оба конца этой связи были сломаны и найдены живой проверкой.
Сначала режим, выбранный моделью, не доходил до кода — клиенту говорили «передам
менеджеру», а дежурному не приходило ничего. Потом перехват оказался
односторонним: менеджер писал клиенту, клиент отвечал в пустоту. Записи ADR-0023
и ADR-0024 — про это.

---

## 4:30 — 6:00 · Персональные данные

**Показать:** написать *«Мой VIN TESTAG00000000910, что с машиной?»*

Ассистент отвечает по карточке. В терминале показать журнал процесса: в модель
ушло `{{VIN_1}}`, клиент увидел свой настоящий VIN.

```bash
python tests/test_pii.py
```

**Сказать:** шлюз закрывает всё, что видит модель, — реплики, карточку владельца,
контекст. Поиск по базе работает **до** шлюза: ему нужны настоящие номера, и он
локальный. За границу процесса уходят уже плейсхолдеры.

Это не украшение: 152-ФЗ требует локализации персональных данных, а модель
учебного контура — зарубежная. Шлюз делает вопрос про юрисдикцию неприменимым,
а не спорным.

---

## 6:00 — 7:30 · Как оно ломается

**Сказать:** отказоустойчивость здесь — не «всё зарезервировано», а «клиент
получает ответ при любом отказе». Проверяется это так:

```bash
python tools/failures.py
```

Восемь способов уронить систему за пару секунд: молчит DMS, протух сток, упал
основной провайдер модели, упали все, ядро выбросило исключение. Ни при одном
клиент не остался без ответа.

**Показать живьём** отказ, который виден в чате:

```bash
python tools/cold.py stale
```

Спросить в боте *«Aurora X5 есть в наличии?»* — ассистент отказывается отвечать
по наличию и предлагает уточнить у менеджера. Вернуть:

```bash
python tools/cold.py fresh
```

**Сказать:** неверный статус хуже отсутствия статуса — он превращается в
обещание. Поэтому при данных старше четырёх часов ассистент замолкает именно по
этой теме, продолжая отвечать по остальным.

**Сказать честно:** два уровня этой лестницы — переход на резервного провайдера
и страховка канала — существовали только в описании архитектуры, пока их не
проверили этим стендом. ADR-0026.

## 7:30 — 8:30 · Фоновый контур и граница

**Показать** в n8n любой из четырёх сценариев: видны записки с целью, блоками и
граблями.

Открыть сценарий «Молчащие лиды» и показать журнал выполнения:

```
Кто замолчал:  {"hours": 24, "dialogs": [2, 3, 4]}
Напомнить:     [{"dialog_id": 2, "sent": true, "route": "service"}]
```

**Сказать:** n8n решает, **когда** действовать. Что сказать и кому — знает только
ядро. Наружу уходят номера диалогов, не люди.

```bash
python tools/check_boundary.py
```

**Сказать:** это и есть доказательство, а не заверение. Журнал не пуст —
идентификаторы в нём есть. Персональных данных при них нет.

## 8:30 — 9:30 · Чем это отличается от демо

```bash
python tools/store.py quality 7
```

Доля «не знаю», доля эскалаций с разбивкой по причинам, доля сработок валидатора.
Три числа отвечают на три разных вопроса: чинить базу знаний, чинить промпт или
разбираться, что именно из двух.

```bash
python tools/versions.py
```

**Сказать:** каждый ответ помечен версией промпта и версией знаний. Когда через
месяц придёт жалоба «бот сказал ерунду», вопрос «а что тогда было написано в
промпте» имеет ответ. Без этой пометки разбор упирается в догадки.

Показать `ENGINEERING_JOURNAL.md`: двадцать шесть записей о том, что решили и
почему. Принятые не переписываются — смена курса заводит новую запись со ссылкой
на заменяемую.

---

## 9:30 — 10:00 · Чего здесь нет

Сказать прямо, до того как спросят:

- **Пилота на живом дилерском центре не было.** Всё на фикстурах: данные
  вымышлены, DMS и CRM — заглушки за портами. Переезд на настоящие системы
  меняет реализацию портов, а не ядро, — но это обещание, а не проверенный факт.
- **Переносимость на GigaChat и YandexGPT не проверена.** Адрес провайдера
  задаётся конфигурацией, резервный провайдер работает, но прогона на российских
  моделях не было.
- **Кластера и высокой доступности нет.** Один процесс, SQLite. Для одного салона
  этого достаточно; для трёх — нет, и в плане это написано.

**Закончить:** проект отвечает не на вопрос «может ли нейросеть отвечать
клиентам» — может, это видно за минуту. Он отвечает на вопрос, **что должно
стоять вокруг неё**, чтобы ей можно было доверить разговор с клиентом.

## Если что-то пошло не так

| Симптом | Причина | Что сделать |
|---|---|---|
| Ассистент молчит в чате | диалог остался за оператором | `/done` в консоли эскалаций |
| Карточка не приходит в консоль | `AVTOGRAD_OPS_IDS` пуст или бот не поднят | проверить `demo_check.py` |
| «По наличию не отвечу» не к месту | сток протух | `python tools/cold.py fresh` |
| n8n: «Forbidden by access permissions» | адрес `localhost` вместо `127.0.0.1` | см. записку «грабли» в сценарии |
| Ответ приходит с задержкой | обращение к модели, 3–8 с | сказать вслух, что ждём модель |
