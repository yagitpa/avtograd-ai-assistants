# База знаний «АвтоГрада»

> **Учебный проект.** Дилер, марки, модели, цены, VIN, имена, телефоны и вакансии вымышлены. Реальные персональные данные не используются и не обрабатываются. Телефоны выбраны в заведомо нероутируемых диапазонах, VIN невалидны по контрольной сумме и начинаются с `TESTAG`.

Этот каталог — слой знаний из ADR-0001. Промпты задают роль, тон и сценарий; факты приходят отсюда. **Нет записи — нет ответа, идёт эскалация.**

## Правила работы с данными

**Фикстуры не редактируются руками.** Источник — `tools/build_fixtures.py`; файлы в `fixtures/` собираются из него. Правка руками потеряется при следующей сборке.

```bash
python tools/build_fixtures.py && python tools/validate_fixtures.py
```

**Валидатор — это критерий приёмки, а не формальность.** 609 проверок: связность ссылок между файлами, соответствие цен прайсу, наличие обязательных полей у статусов, покрытие сценариев, тестовость телефонов, отсутствие в карточках кандидатов полей, по которым нельзя отсеивать. Правило простое: если проверка не проходит, данные нельзя использовать в промптах.

**Коды латиницей, подписи кириллицей.** Код обслуживания — `TO-1`, подпись для клиента — «ТО-1 (15 000 км)» в поле `display_name`. Кириллическое «ТО» визуально неотличимо от латинского `TO`, и смешение ломает поиск молча. Валидатор это проверяет.

**У каждой записи есть владелец и дата.** В фикстурах — блок `_meta` с `owner` и `updated_at`, в записях базы знаний — те же поля. Просроченная запись помечается «требует подтверждения», а не удаляется.

## Сценарные крючки

Данные собраны не «для объёма» — в них заложены конкретные ситуации, которые нужно будет проверить на этапе 3:

- Aurora X5 Comfort — **два автомобиля в наличии**: базовый сценарий подбора
- Aurora S7 2020 — **продан 10 сентября**: сценарий «машину уже купили»
- Vector Sedan 2022 — **в резерве до 14 сентября**
- Aurora S7 Prestige — **на предпродажной подготовке**, готовность 13 сентября
- Aurora X3 Style — **в пути**, ожидается 25 сентября
- Vector Sedan 2018, 3 владельца, перекрас 3 элементов — разговор об оценке трейд-ин
- `veh-05` (Aurora S7) — **три обращения по одному стуку**, простой 11 дней: конфликтный сценарий
- `veh-03` (Aurora X3) — ТО-3 пропущено, клиент заявляет обслуживание в стороннем сервисе
- `veh-10` (Aurora X3) — **сейчас в ремонте**: сценарий «что с моей машиной»
- `ACT-102` — **истёкшая акция**: ассистент не должен её предлагать
- 5 кандидатов со стоп-факторами — проверка отсева без дискриминации
